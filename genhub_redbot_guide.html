🚀 GenHub Cog: Discord Bot & GitHub Router

The definitive, zero-terminal guide for installing, configuring, diagnosing, and updating the GenHub Cog on any RedBot instance. Designed for high-activity developer communities with rate limiting, open-only PR reconciliation, and selective role mentions.

📦 Cog Version: v1.2.0 (Latest)
🤖 Target: RedBot 3.5.0+
🌐 Webhook Port: 0.0.0.0:8080
🎯 All-In-One Setup: !genhub setup

Click any of the code boxes below to copy the command directly to your clipboard:

Add the GenHub Repository

📡 Dual-Feed Routing Architecture

How GenHub Cog separates deep discussions from high-level channel notifications to keep your community clean and organized:

📁 Forum Feeds (The Workspace)

Forum Channels

Target: github-issues-feed & pull-requests-feed

  • Creates a dedicated post/thread for every PR or Issue: [GH] [#104] Title
  • Contains full descriptions, labels, and status tags (Open, Merged, Closed)
  • Forwards all deep comment discussions, review comments, and code diff notes inside the thread

💬 Chat Channels (The Birds-Eye View)

Text Channels

Target: issues-chat & pull-requests-chat

  • High-level status alerts only: PR opened, PR merged, PR closed, Issue opened/closed
  • Includes clickable links to the Forum Thread and the GitHub URL
  • Role mention (@Contributor) pings only on New PRs and Merges
  • Zero comment spam: comments stay in the thread!

Comment Formatting & Mentions

Rules for notifications, role mentions, and GitHub comment formatting in Discord threads:

Role Mention Rules

Role mentions (@Contributor) are only sent when a PR is opened or merged. All issue creations, issue comments, reviews, and closed unmerged PRs post without role mentions.

Markdown Cleaning & Embed Formatting

GitHub comments are parsed into Discord embeds, removing raw HTML tags (<details>, <summary>, <!-- -->). Automated bot reviews post the primary summary embed, aggregating any additional line notes into the embed footer.

  • Content type: application/json
  • Secret: (Optional, set via !genhub secret <secret> if configured)
  • Events to select:
    • ☑️ Issues

    • ☑️ Issue comments
    • ☑️ Pull request reviews
