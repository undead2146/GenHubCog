🚀 GenHub Cog: Discord Bot & GitHub Router

The definitive, zero-terminal guide for installing, configuring, diagnosing, and updating the GenHub Cog on any RedBot instance. Designed for high-activity developer communities with rate limiting, open-only PR reconciliation, and selective role mentions.

📦 Cog Version: v1.2.0 (Latest)
🤖 Target: RedBot 3.5.0+
🌐 Webhook Port: 0.0.0.0:8080
🛡️ Push Protection: Cleaned & Verified

⚡ Option A: 3-Step In-Discord Installation (Recommended)

If you already have a RedBot instance running, you do not need terminal access. You can add the repository and install the cog directly inside Discord using standard Downloader commands.

1

Add the GenHub Repository

Tell your RedBot instance where to find the official GenHub Cog repository:

!repo add genhubcog https://github.com/undead2146/GenHubCog
2

Install the Cog

Download and compile the cog package into your bot storage:

!cog install genhubcog GenHub
3

Load the Cog

Activate the cog and start the internal webhook server:

!load GenHub

🛠️ Step-by-Step Channel Configuration in Discord

Right-click each channel in your Discord server (with Developer Mode turned on) to copy its ID, then execute these configuration commands:

📁 1. Set Forum Channels

Link your GitHub Issues forum and Pull Requests forum:

!genhub issuesforum <issues_forum_id>
!genhub prsforum <prs_forum_id>
🔔 2. Set Log Channel & Roles

Configure bot error alerts and the role to mention on PR merges:

!genhub logchannel <log_channel_id>
!genhub contributorrole <role_id>
🐙 3. Add Tracked Repositories

Add the repositories that the bot is allowed to ingest webhooks for:

!genhub addrepo community-outpost/GenHub
🔑 4. Add GitHub API Token

Personal access token used for rate-limited API queries and comment sync:

!genhub token <github_pat_token>

🔄 Updating the Cog via Discord

Whenever new updates or fixes are pushed to GitHub, RedBot owners can update their installation in Discord with zero downtime.

📡 1. Check for Updates

Check if a newer version exists on GitHub:

!cog checkforupdates
🚀 2. Apply Update & Reload

Pull the latest version and reload the cog into memory:

!cog update GenHub
!reload GenHub
🔔 Notification & Role Mention Policy: Role mentions (@Contributor) are triggered **ONLY** when a New PR is Opened or an existing PR is Merged. Regular comments, issue creations, closed unmerged PRs, and reviews create threads cleanly with zero notification spam.

🐙 GitHub Webhook Configuration Checklist

⚙️ In your GitHub Repository Settings (Settings > Webhooks > Add webhook):
  • Payload URL: http://<YOUR_SERVER_IP>:8080/github (or /webhook)
  • Content type: application/json
  • Secret: (Optional, set via !genhub secret <secret> if configured)
  • Events to select:
    • ☑️ Issues
    • ☑️ Pull requests
    • ☑️ Issue comments
    • ☑️ Pull request reviews
    • ☑️ Pull request review comments
